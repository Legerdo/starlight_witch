# Starlight Witch

밤하늘 아래 폐허에서 마녀가 별빛 마법을 시전하는 16비트 스타일 픽셀 아트 애니메이션입니다.

**[웹에서 보기](https://legerdo.github.io/starlight_witch/)**

## 특징

- HTML Canvas로 그리는 128 × 96 픽셀 장면
- 대기 → 마법 충전 → 발사 → 충돌 → 회복으로 이어지는 6초 반복 애니메이션
- 화면 크기에 맞춘 정수 배율 확대와 픽셀 렌더링
- 시스템의 동작 줄이기 설정에 따라 화면 흔들림과 시전 섬광 완화
- 외부 라이브러리, 이미지 파일, 설치 또는 빌드 없이 실행

## 로컬 실행

`starlight_witch.html`을 브라우저에서 열면 자동으로 재생됩니다. 별도의 조작은 필요하지 않습니다.

## 배포

GitHub Pages가 `main` 브랜치의 저장소 루트(`/`)를 게시합니다.
`index.html`은 원본 `starlight_witch.html`로 이동하는 진입 페이지입니다.
원본을 수정하고 `main`에 커밋·푸시하면 공개 페이지가 갱신됩니다.
